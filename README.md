# 🚗 Garage Manager

A full-stack **MERN (MongoDB, Express.js, React.js, Node.js)** web application for managing vehicles, service history, and fuel records.

## 📸 Preview

> Screenshots will be added after the UI is completed.

---

## ✨ Features

### 🔐 Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes

### 🚗 Vehicle Management
- Add Vehicle
- View Vehicles
- Edit Vehicle
- Delete Vehicle
- Search Vehicles
- Filter by Fuel Type

### 🔧 Service Management
- Add Service Record
- View Service History
- Update Service
- Delete Service

### 📊 Dashboard
- Total Vehicles
- Petrol Vehicle Count
- Diesel Vehicle Count
- Search & Filter

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/kushalg2002/garage-manager.git
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
npm run dev
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the `server` folder.

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_CONNECTION_STRING

JWT_SECRET=YOUR_SECRET_KEY
```
